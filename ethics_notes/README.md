   - **મુદ્દો:** નૈતિકતા અને માનવ સંવાદ (ભાગ ૨): નૈતિકતાના પરિણામો (વ્યક્તિગત, સામાજિક, આર્થિક, શાસકીય), માનવ મૂલ્યો (સાધ્ય મૂલ્યો Terminal Values વિ. સાધન મૂલ્યો Instrumental Values), મહાન નેતાઓ અને સુધારકોના ઉપદેશો (મહાત્મા ગાંધી - ૭ સામાજિક પાપો & ટ્રસ્ટીશીપ, સ્વામી વિવેકાનંદ - દરિદ્ર નારાયણ, ડૉ. આંબેડકર - બંધારણીય નૈતિકતા, સરદાર પટેલ - સ્ટીલ ફ્રેમ, ડૉ. કલામ - વિનમ્રતા), મૂલ્ય ઘડતરમાં પરિવાર, શિક્ષણ અને સમાજની ભૂમિકા.

   - **મુદ્દો:** નાગરિક સેવાઓ માટે મનોવલણ (ભાગ ૧): અંગત વિ. જાહેર જીવનમાં નૈતિકતા (સગાવાદ અટકાવવો, હિતોનો સંઘર્ષ, બિલ ક્લિન્ટન કેસ), મનોવલણ (Attitude) નો અર્થ, વ્યાખ્યા અને વિશેષતાઓ, "Attitude matters the most" (સિંહ, ગરુડ, એમ.એસ. ધોની, યુવરાજ સિંહ), મનોવલણનું CAB ત્રિ-પરિમાણીય મોડેલ (Cognitive - બોધાત્મક, Affective - ભાવાત્મક, Behavioral - વર્તનાત્મક), વાસ્તવિક કેસો (માર્લબોરો સિગરેટ બ્રાન્ડિંગ, ચૂંટણી અને રાષ્ટ્રવાદ, સામાજિક જ્ઞાતિવાદ, માર્કેટિંગમાં ભય/લાલચ), સનદી સેવામાં યોગ્યતા (Aptitude) વિ. મનોવલણ (Attitude) નું મહત્વ.
